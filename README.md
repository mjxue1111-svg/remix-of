# Remix of 充值平台客户端

请生成一张中文企业级 SaaS 产品信息架构图，标题为「充值平台客户端界面架构图（一期）」。

画面采用白色背景、蓝色主色、浅蓝和浅灰辅助色，整体风格简洁、专业、清晰，适合放入 PRD 或产品汇报文档。使用圆角矩形、清晰连线和模块化结构，不要复杂插画，不要过度装饰，保证中文文字清晰可读。

图中顶部居中展示标题「充值平台客户端界面架构图（一期）」，标题下方放置主节点「客户端」。

从「客户端」向下分出三个一级模块，横向三栏排列：

1. 注册 / 登录

2. 充值

3. 余额流水看板

左侧模块为「注册 / 登录」，使用用户或登录图标，下面包含三个子功能：

- 手机号 / 账号登录

- 企业信息完善

- 联系人信息维护

中间模块为「充值」，作为核心模块，视觉上适当放大或突出，使用钱包、充值或资金图标。该模块下分为三组功能：

第一组「发起充值」：

- 选择星图账户

- 填写充值金额

- 填写应付金额 / 折扣

- 提交充值申请

第二组「付款回单」：

- 查看收款信息

- 上传付款回单

- 查看财务确认状态

第三组「充值进度」：

- 待审核

- 待打款

- 待确认到账

- 平台转账中

- 充值完成

右侧模块为「余额流水看板」，使用图表或数据看板图标，下面包含四个子功能：

- 账户余额

- 充值记录

- 消耗流水

- 流水明细

整体布局要求：

- 横向三栏结构

- 「充值」模块位于中心并作为视觉重点

- 一级模块使用深蓝色标题条

- 子功能使用浅蓝色圆角卡片

- 层级清晰，连线整齐

- 字体使用清晰的中文黑体或无衬线字体

- 图形风格为产品架构图 / 界面架构图，而不是流程图
